# Python Learning Lab

A collection of Python scripts and Jupyter notebooks created to practice programming, explore new concepts, and experiment with different computational techniques.

This repository brings together exercises, academic assignments, algorithm implementations, and small experiments in data analysis, machine learning, computer vision, and optimization.

## Topics Covered

- **Data Analysis:** Data exploration, correlation analysis, and data visualization using heatmaps.
- **Machine Learning:** Supervised classification, regression, and deep learning models.
- **Computer Vision:** Image processing and computer vision experiments using OpenCV.
- **Optimization Algorithms:** Genetic algorithms, multi-objective optimization, and NSGA-II.
- **Data Visualization:** Exploring datasets and presenting results through visualizations.
- **Programming Exercises:** Recursive algorithms, maze-solving problems, and game implementations.
- **Academic Projects:** Notebooks developed for coursework, technical assessments, and independent study.

## Repository Structure


- `assets/`: Supporting files and resources used in the notebooks.
- `sample_data/`: Sample datasets and other data files used for experimentation.

## Getting Started

### Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- The Python libraries required by each notebook

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ana-athayde/python-learning-lab.git
   cd python-learning-lab
   ```

2. Create and activate a virtual environment (optional but recommended):

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install Jupyter:

   ```bash
   pip install jupyter
   ```

4. Install any additional dependencies required by the notebook you want to run.

5. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

This repository serves as a personal learning space for practicing Python, testing ideas, exploring algorithms, and developing practical skills in data science, machine learning, and computational problem-solving.
